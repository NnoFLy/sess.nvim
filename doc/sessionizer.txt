==============================================================================
INTRODUCTION                                                  *sess.nvim*

sess.nvim manages Neovim sessions in a workflow similar to
"tmux-sess".

Core features:
  - Save and load sessions
  - Pin and rename sessions
  - Delete sessions
  - List sessions (via telescope.nvim)
  - Jump to the last session

Quick start:
  1. Install the plugin.
  2. Call |sess.setup| once in your config.
  3. Use |:Sess| commands or the Lua API.

==============================================================================
REQUIREMENTS                                           *sess-requirements*

Required:
  - Neovim

Optional (only for |:Sess| list):
  - telescope.nvim
  - plenary.nvim

==============================================================================
CONFIGURATION                                               *sess-setup*

sess.setup({opts})                                  *sess.setup*
    Configure sess.nvim. Call once in your config.

    Usage:
    >
      require("sess").setup({
          paths = {
              "path/to/your/projects/*",  -- adds all folders in this path
              "path/to/your/project",     -- adds this folder
          },
          smart_auto_load = true,  -- auto load session on "nvim" only
          auto_save = true,        -- auto save on exit if a session is loaded
          exclude_filetypes = { "gitcommit" },
          log_level = "info",      -- debug|info|warn|error
          before_load = {
              auto_save_files = false,
              auto_hide_buffers = true,
              custom = function() end,
          },
          after_load = {
              custom = function() end
          },
          on_unload = { -- runs after session is unloaded or deleted
              custom = function() end
          }
      })
    <

    Keys:
      paths                 (table)    List of project paths or globbed folders.
      smart_auto_load       (boolean)  Auto load only when starting with `nvim`.
      auto_save             (boolean)  Auto save on exit if a session is loaded.
      exclude_filetypes     (table)    Filetypes excluded from auto save.
      log_level             (string)   debug|info|warn|error.

      before_load           (table)    Hooks before a load occurs.
        auto_save_files     (boolean)  Save files before load.
        auto_hide_buffers (boolean)  Remove buffers before load.
        custom              (function) Custom hook.

      after_load            (table)    Hooks after load.
        custom              (function) Custom hook.

      on_unload             (table)    Hooks after unload or delete.
        custom              (function) Custom hook.

Notes on Auto Load:                                       *sess-autoload*
  smart_auto_load only loads a session when Neovim is started without a file
  or directory argument:
    - "nvim" loads the session for the current working directory (if present)
    - "nvim file.txt" or "nvim ." does not auto load

==============================================================================
COMMANDS                                                   *sess-commands*

All commands are available through |:Sess|.

:Sess save                                                *:Sess-save*
    Save current session.

:Sess pin [<session_name>]                                *:Sess-pin*
    Toggle the pinned state of a session.
    If <session_name> is omitted, the current session is used.

:Sess create [<path>]                                     *:Sess-create*
    Create a session for <path> and load it.
    If a session already exists for <path>, it is loaded instead.
    If <path> is omitted, current working directory is used.

:Sess load [<session_name_or_path>]                        *:Sess-load*
    Load session by name, path, or current working directory.

:Sess unload                                              *:Sess-unload*
    Unload current session.

:Sess rename [<session_name>]                             *:Sess-rename*
    Rename session by name or current session.

:Sess delete [<session_name>]                             *:Sess-delete*
    Delete session by name or current session.

:Sess last                                                *:Sess-last*
    Load the previous session.

:Sess list                                                *:Sess-list*
    List sessions (requires telescope.nvim).

Completion:
  :Sess <Tab>                  completes subcommands.
  :Sess load|pin|rename|delete <Tab>  completes session names.
  :Sess create <Tab>           completes directories.

KEYMAPS                                                   *sess-keymaps*

Example mappings:
>
  vim.keymap.set("n", "<M-s>s", "<cmd>Sess save<cr>",
    { desc = "Save session" })
  vim.keymap.set("n", "<M-s>c", "<cmd>Sess pin<cr>",
    { desc = "Pin session" })
  vim.keymap.set("n", "<M-s>a", "<cmd>Sess load<cr>",
    { desc = "Load session" })
  vim.keymap.set("n", "<M-s>u", "<cmd>Sess unload<cr>",
    { desc = "Unload session" })
  vim.keymap.set("n", "<M-s>l", "<cmd>Sess list<cr>",
    { desc = "List sessions" })
  vim.keymap.set("n", "<leader><C-^>", "<cmd>Sess last<cr>",
    { desc = "Load the previous session" })
<

==============================================================================
STATUSLINE                                               *sess-statusline*

Show current session in your statusline:
>
  local statusline = vim.o.statusline

  require("sess").setup({
      log_level = "error",
      after_load = {
          custom = function()
              local session = ("[" .. vim.g.sess_current_session .. "] ")
                              or ""
              vim.o.statusline = session .. statusline
          end
      },
      on_unload = {
          custom = function()
              vim.o.statusline = statusline
          end
      }
  })
<

TELESCOPE                                               *sess-telescope*

Load extension:
>
  require("telescope").load_extension("sess")
<

Default config:
>
  local sess_actions =
      require("telescope._extensions.sess.actions")

  require("telescope").setup({
      extensions = {
          sess = {
              prompt_title = "All sessions",
              mappings = {
                  ["i"] = {
                      ["<C-d>"] = actions.delete_session,
                      ["<Tab>"] = actions.toggle_pin_session,
                      ["<C-r>"] = actions.rename_session,
                      ["<CR>"] = actions.enter,
                  },
                  ["n"] = {
                      ["dd"] = actions.delete_session,
                      ["rr"] = actions.rename_session,
                      ["<Tab>"] = actions.toggle_pin_session,
                      ["<CR>"] = actions.enter,
                  },
              },
          }
      }
  })
<

LUA API                                                      *sess-api*

The programmatic API lives in lua/sess/api/ and is pure logic (no prompts, no
logging). It is exposed as:                          *sess-api.modules*
>
  local api = require("sess.api")
  -- api.session - pure operations
  -- api.state   - current / prev / active getters
  -- api.items   - get_items() for lists
  -- api.opts    - setup() / get()
<
All api.session functions return (ok, err, ...). Session/state objects
returned from the API are defensive copies; mutating them does not mutate
internal plugin state.

api.session.create({cwd}?, {opts}?)              *sess-api.session.create*
  Validate the directory, save the current session, chdir + hide buffers +
  `edit .`, create the session, and wire current/prev/active state. The
  working directory is restored when creation fails.
  Return: ~
      boolean, string?, sess.Session

api.session.save({target}?)                      *sess-api.session.save*
  nil = current session. A string resolves as id/name/path first; an existing
  target is saved from its recorded cwd. If the string is a directory without
  a session, a session is created for that directory. Temporary chdir changes
  are restored before returning.
  Return: ~
      boolean, string?, sess.Session

api.session.load({target}?, {opts}?)             *sess-api.session.load*
  nil = resolve by current cwd. Merges before_load/after_load defaults,
  errors on unsaved buffers when auto_save_files=false, saves the current
  session before switching. Hook failures are returned as errors. {opts} may
  carry per-call {before_load}/{after_load} overrides. Implemented as
  {prepare} + {commit} so UI layers can prompt in between.
  Return: ~
      boolean, string?, sess.Session, boolean (already-loaded)

api.session.prepare({target}?, {opts}?)          *sess-api.session.prepare*
  Resolve the target and run the pre-load guard: merge before_load/after_load
  defaults, modified-buffer check, {wall}, and {before_load.custom}. Returns
  the merged before_load/after_load options for later {commit}.
  Return: ~
      boolean, string?, sess.Session, table, table

api.session.commit({session}, {opts}?)           *sess-api.session.commit*
  Run the switch itself: hide buffers, apply the session, wire current/prev
  state, run {after_load.custom}. Assumes the current session was already
  saved by the caller (use {M.load} or save + prompt in the UI layer).
  Return: ~
      boolean, string?, sess.Session, boolean (already-loaded)

api.session.unload({opts}?)                     *sess-api.session.unload*
  Unload the current session. Returns (false, "no current session") when
  nothing is loaded. {opts} may carry an {on_unload} override. Hook failures
  are returned after state has been cleared.
  Return: ~
      boolean, string?

api.session.delete({target}, {opts}?)           *sess-api.session.delete*
  Delete a session. No confirm prompt. Clears state if the deleted session
  is current, runs merged on_unload. {opts} may carry an {on_unload}
  override.
  Return: ~
      boolean, string?, sess.Session

api.session.rename({target}, {name})            *sess-api.session.rename*
  Rename a session. {name} is required (no input() prompt).
  Return: ~
      boolean, string?, sess.Session

api.session.toggle_pin({target})                *sess-api.session.toggle_pin*
  Toggle the pinned state of a session.
  Return: ~
      boolean, string?, sess.Session

api.session.resolve({target})                   *sess-api.session.resolve*
  Shared target resolution:
    - nil          -> the current session
    - table        -> used as-is (session or picker entry with id + metadata)
    - string       -> try id, then name, then path
  Return: ~
      boolean, string?, sess.Session

Queries                                      *sess-api.session.queries*
  Query functions also use `(ok, err, ...)`. `list()` may return a partial
  session list together with an error when one stored session is corrupted.
>
  local ok, err, sessions = api.session.list()
  local ok, err, s = api.session.get_by_id(id)
  local ok, err, s = api.session.get_by_name(name)
  local ok, err, s = api.session.get_by_path(cwd)
<
  Return: ~
      boolean, string?, sess.Session[] | sess.Session | nil

api.state                                          *sess-api.state*
>
  local current = api.state.current()   -- sess.Session | nil
  local prev    = api.state.prev()      -- sess.Session | nil
  local active  = api.state.active()    -- sess.Session[]
<

api.items                                         *sess-api.items*
>
  local items = api.items.get_items()   -- (Session | DirectoryItem)[]
<

api.opts                                           *sess-api.opts*
>
  api.opts.setup({opts})   -- equivalent to require("sess").setup({opts})
  local opts = api.opts.get()
<

==============================================================================
TROUBLESHOOTING                                          *sess-troubleshooting*

Conform.nvim and before_load.auto_save_files = true
If you use conform.nvim and enable before_load.auto_save_files, you may need
to remove format_after_save and use format_on_save instead:
>
  require("conform").setup({
      formatters_by_ft = { ... },
      format_after_save = { lsp_format = "fallback", timeout_ms = 500, async = true },
      format_on_save = { timeout_ms = 500, lsp_format = "fallback" },
  })
<

Alternatively, set before_load.auto_save_files = false.
